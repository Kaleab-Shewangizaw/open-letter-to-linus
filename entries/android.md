# Android

Android exists because Linux exists — and because Linus Torvalds created a kernel that was open, adaptable, and scalable.

When Google started Android in 2007, they chose the Linux kernel as the foundation for their operating system. The kernel’s stability, open nature, and community support made it possible to build a mobile OS that could run on thousands of devices.

Linux provided:
- hardware abstraction for mobile devices
- security and process isolation
- networking support
- adaptability for different architectures

Today, Android powers billions of smartphones worldwide and is one of the most successful Linux-based projects ever.

Because Linux exists, Android exists.
