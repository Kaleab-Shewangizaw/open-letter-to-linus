# Git

Git exists because Linux exists — and because of the way Linux was built.

In 2005, while working on the Linux kernel, Linus Torvalds needed a version control system that was fast, distributed, and did not get in the way of developers. Existing tools at the time didn’t match the scale or workflow of kernel development.

So he built one.

Git was designed around the needs of Linux:
- distributed development
- speed over networks
- trust in developers
- simple core concepts
- no central authority

What started as an internal tool for the Linux kernel quickly became the foundation of modern software development.

Today, Git powers:
- open-source collaboration
- platforms like GitHub, GitLab, and Bitbucket
- workflows used by millions of developers every day

Git is not just a tool.
It is a reflection of the Linux philosophy: decentralization, pragmatism, and trust in people who write code.

Because Linux exists, Git exists.
