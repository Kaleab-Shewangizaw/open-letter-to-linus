# Open Source Culture

Open source culture exists because Linux exists — and because Linus Torvalds insisted that software should be shared and improved collaboratively.

The Linux kernel became successful not just because of its code, but because it was open to contributions from anyone in the world. Linus designed the process to be meritocratic, transparent, and collaborative.

This philosophy gave rise to:
- Communities of developers contributing globally
- Projects like Apache, Kubernetes, and Node.js
- Platforms like GitHub and GitLab where collaboration is the norm

Open source culture taught developers to value:
- sharing over secrecy
- merit over hierarchy
- collaboration over competition

Because Linux exists, a global culture of open software exists.
