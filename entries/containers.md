# Containers

Containers exist because Linux exists — and because the Linux kernel introduced features like namespaces and cgroups that made isolated, lightweight environments possible.

Linux allowed developers to:
- isolate processes
- control resources
- build reproducible environments

These features became the foundation of container technologies like:
- Docker
- Kubernetes
- LXC

Containers changed how software is deployed, making it portable, scalable, and efficient.

Because Linux exists, modern containers exist.
