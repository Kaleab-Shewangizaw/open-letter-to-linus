# Supercomputing

Supercomputing exists because Linux exists — and because Linus Torvalds made a kernel that could scale from personal computers to the world’s fastest machines.

Today, most of the top supercomputers run Linux because it is:
- highly customizable
- stable under extreme loads
- scalable across thousands of cores
- supported by a large developer community

Linux powers scientific research, climate modeling, and artificial intelligence at scale.

Because Linux exists, high-performance computing exists.
