# open-letter-to-linus

**open-letter-to-linus** is an open, community-driven repository where developers come together to write about **Linus Torvalds** — his work, his words, and the impact he has had on technology and on our lives.

This is not a biography and not a documentation project.

It is a shared space for:
- stories,
- reflections,
- quotes,
- ideas,
- and technologies that exist because of Linux and the culture around it.

Everyone can read.  
Everyone can write.  
Open like Linux itself.

---

## Why this repository exists

Linux changed how software is built, shared, and maintained.  
Linus Torvalds didn’t just write code — he influenced a mindset that shaped generations of developers.

This repository exists as a **public, open letter**, written collectively by developers around the world, to acknowledge that impact.

Some people will write technical reflections.  
Some will write personal stories.  
Some will just share a quote that meant something to them.

All of it belongs here.

---

## Repository structure

entries → Things that exist because of Linux or Linus’ work
/quotes → Linus Torvalds’ quotes (with or without explanations)
/stories → Developer stories, thoughts, links, and reflections


There are no strict rules on length or writing style.  
Clarity and respect matter more than perfection.

---

## How to contribute

Contributing is intentionally simple.

1. Fork the repository
2. Add **one file** in the appropriate folder:
   - `/entries` for technologies or ideas
   - `/quotes` for quotes
   - `/stories` for personal reflections or links
3. Open a pull request

You may include your GitHub profile or personal site at the end of your file if you want.  
Anonymous contributions are also welcome.

If you’re not sure where your contribution fits, that’s okay. Choose what feels right.

---

## What this repo is (and is not)

This repo **is**:
- open
- community-written
- respectful


This repo is **not**:
- a place for arguments or flame wars
- a ranking of people or opinions
- an attempt to speak *for* Linus

It’s simply developers writing, together.

---

## A note on respect

Linus Torvalds is a public figure with strong opinions.  
You don’t have to agree with everything to contribute here.

Write honestly, write thoughtfully, and keep it respectful.

---

## Closing

you already have something worth writing here.

Leave your mark.
